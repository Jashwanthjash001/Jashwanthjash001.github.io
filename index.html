How I work

I'm a software engineer focused on generative AI and LLM inference. Day to day I build agentic pipelines, RAG systems, and serving infrastructure — and lately I've been pushing most of it on-device, because that's where a lot of real teams actually need LLMs: compliance, cost, and latency rule out sending data to a hosted model.

I like projects where I can measure the thing instead of guessing — a perplexity-vs-speed-vs-size table, a latency-vs-throughput curve, a before/after exact-match number. My repos keep honest status notes and real results, including the limitations.

Currently going deeper on: inference optimization (batching internals, KV-cache, CUDA / kernel-level — learning), fine-tuning beyond toy tasks, and agent tooling via MCP.
